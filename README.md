# A股收盘档案

面向个人收盘后复盘的纯静态网页，包含市场总览、情绪周期、板块复盘、辨识度观察、机构调研和复盘笔记六个模块。

## 直接查看

直接打开 `index.html` 即可使用。仓库当前附带最新生成的真实收盘快照，页面不需要前端构建工具或本地服务器；只有 `market-data.js` 缺失或结构无效时，才会切换到明确标注的演示兜底快照。

## GitHub Pages 自动更新

`.github/workflows/pages.yml` 负责发布静态站点，并在北京时间周一至周五18:00自动生成最新市场快照。GitHub Actions 的定时任务可能有数分钟延迟；若当天不是交易日，工作流会保留上一个交易日快照，不创建无意义的数据提交。

也可以在 GitHub 仓库的 `Actions` 页面手动运行“更新市场数据并部署”，手动运行会允许在同一交易日重新抓取并修复缺失数据。

## 生成真实数据

建议使用 Python 3.10 或更高版本：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 scripts/build_market_data.py
```

首次验证接口时可以缩小扫描范围：

```bash
python3 scripts/build_market_data.py --quick
```

脚本会把真实快照原子写入 `market-data.js`。原始接口响应缓存在 `.cache/akshare/`，单个接口失败时优先使用缓存并把告警写入页面；全市场行情不可用时不会覆盖现有快照。历史涨跌家数、成交额和情绪字段会按交易日从上一份真实快照继续累积，不会用模拟值填空。

## 指标口径

- 股票范围：沪深京全A，排除 ST、退市整理和名称带 `N`/`C` 的近期上市股票。
- 情绪得分：涨停20%、跌停反向15%、炸板率反向15%、昨日涨停溢价20%、1进2为10%、2进3为10%、最高连板10%。
- 板块涨幅：按当前收盘价相对1、3、7个交易日前收盘价计算。
- 机构调研：提供过去7天、30天和半年（180个自然日，均含首尾日）三个窗口，按总市值50–100亿、100–300亿、300–800亿分档。
- 累计接待机构数：窗口内各场机构调研公告披露的“接待机构数量”之和，同一机构参加多场会重复计入，因此不是去重机构数。
- 买入评级机构数：归一化买入、增持、推荐、强烈推荐、强推和优于大市，同日同机构同标题的报告先去重，再统计发布积极评级的机构去重数量。
- 半年涨幅：120个交易日复权收盘价涨幅。

## 测试

```bash
python3 -m unittest discover -s tests -v
node --check app.js
```

复盘笔记保存在浏览器 `localStorage`，支持 JSON 导出和导入。页面数据只用于研究与复盘，不构成投资建议。
